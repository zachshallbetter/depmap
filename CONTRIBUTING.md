# Contributing to depmap

Thanks for your interest. This repository currently holds the README (the tool's
documentation), three design drafts (`Setup.md`, `Additions.md`, `Inferance.md`) and a
placeholder `package.json`. It has no source tree, build step or test suite yet, so there
are no setup or test commands to run: the `test` script in `package.json` is npm's
"no test specified" placeholder.

## Making a change

- Open an issue or a PR with clear reproduction steps, as the README asks.
- Keep the README, the drafts and `package.json` consistent with each other (for example,
  version and license).
- State only what the repository supports; do not document a command that does not exist
  here.
- Commit history has no enforced format. Use a short, imperative summary, with a
  conventional prefix such as `docs:` or `fix:` when it fits.

## Pull requests

- Branch off `main`; keep PRs focused.
- Describe the change and how you verified it. The PR template prompts for this.
- Participation is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
